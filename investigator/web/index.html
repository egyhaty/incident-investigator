    WHAT IS ACTUALLY HAPPENING?

    One loop. Three building blocks.

    01

    The investigator

    In LLM mode, the model chooses its next tool based on previous observations. A fixed budget keeps the investigation bounded. Demo mode uses a transparent reference policy instead.

    02

    The tools

    Six allowlisted functions read scenario evidence and search runbooks. There is no shell, mutation tool, arbitrary URL fetch, or live Kubernetes connector.

    03

    The knowledge

    BM25 retrieves relevant runbook sections. The response cites retrieved chunks and observed evidence. Missing evidence must lead to uncertainty, not an invented diagnosis.

    THE PLATFORM STORY

    Platform first. Reasoning second.

    Karm DevOps builds the Kubernetes and GitOps foundation. This lab investigates incidents above it with bounded tools, runbooks, and evidence checks.
