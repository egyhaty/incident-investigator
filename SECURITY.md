# Security policy

The public project contains synthetic fixtures only. Please do not report real credentials, customer data, private hostnames, or production incident details in a public issue.

The demo server is not a hardened public multi-user service. Keep the application behind authentication and a reverse proxy, and keep Ollama bound to loopback. Any future live evidence connector must use least-privilege, read-only credentials with explicit scope and redaction.

For a suspected security issue, contact the maintainer privately through the contact details on the GitHub profile rather than opening a public issue.
